# Network Intrusion Detection and Real-Time Security Monitoring System

## Project Name
Cyber Security Network Monitor

## Objective
The objective is to develop a cybersecurity monitoring solution capable of observing network activity, identifying suspicious behavior, and generating security alerts.

## Problem Statement
Modern networks face threats such as scanning attacks, abnormal traffic patterns, and unauthorized access attempts. Manual monitoring is inefficient, so automated intrusion detection is required.

## Methodology
The system collects packets, analyzes network behavior using rules, stores events in SQLite, and presents results through a dashboard.

## Implementation
Modules:
- Network Monitor
- Packet Analyzer
- Intrusion Detector
- Logger
- Database Manager
- Dashboard
